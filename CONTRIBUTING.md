# Contributing

This is not an official Bancontact project. It is the overview repository of independent, unofficial, open source Bancontact Pro SDKs.

## What is welcome

- **Bug reports**, with the bug report template. Include the SDK, its version, the runtime, what you expected and what happened.
- **Suggestions**, with the feature request template.
- **Pull requests** in the repository of the SDK concerned. Open an issue first for anything larger than a small fix, so the direction can be agreed.

By submitting a contribution you license it under the Apache License 2.0, as section 5 of that licence provides. There is no contributor agreement to sign.

## Before you post

Issues and pull requests are public. Never include API keys, private keys, production merchant profile IDs, payment data or personal data.
