# Security policy

This is not an official Bancontact project. These SDKs are independent and based on Bancontact's public documentation.

## Reporting a vulnerability

**Do not report vulnerabilities in a public issue.** Issues in this repository are public, and a public report puts users at risk before a fix exists.

> **TODO:** the confidential channel for security reports is still to be confirmed. Until it is published here, do not post details of a vulnerability anywhere public. You may open a public issue that says only that you have found a security problem and want a confidential way to share it, without any technical detail.

## What to include, once a channel exists

- the SDK and its version, and the runtime
- what the problem is and what an attacker could do
- steps to reproduce, without real keys, production merchant profile IDs or payment data

## Scope

Vulnerabilities in the SDKs and their documentation. Problems in the Bancontact Pro API itself or in Bancontact's systems are for Bancontact.
