# BancontactPro.SDK documentation

> **This is not an official Bancontact project.** The SDKs are independent and based on Bancontact's public Bancontact Pro documentation.

This is the overview for the unofficial, open source Bancontact Pro SDKs (.NET, TypeScript, Python, PHP). The code of each SDK lives in its own repository; this repository holds the overview, these pages and the issue tracker.
