# Roadmap

The state of the unofficial Bancontact Pro SDKs as of 24 October 2026. Nothing has been published yet, and no package names are reserved.

| Language | Package name (proposal) | State |
|---|---|---|
| .NET | `BancontactPro.Net` | In development. Payment, Refund and Reconciliation APIs, request signing and webhook verification exist. |
| TypeScript | `@dewall88/bancontactpro` | In development. Same API coverage, no runtime dependencies. |
| Python | `bancontactpro` | In development. Same API coverage, async. |
| PHP | `dewall88/bancontactpro` | In development. Same API coverage, PSR-18. |

## What has to happen first

- Agree the use of the Bancontact names with Bancontact, and settle the package names.
- Check the repositories for secrets and drafts before they become public.
- Publish the first preview packages.

## Samples

Each language has a sample web UI in its own repository. They build on the sister repositories until the packages are published, after which they use only the published packages.

## Where to follow progress

Questions go through [issues](https://github.com/yvebrecht/BancontactPro.SDK/issues); they are public, so do not post confidential information.
